# Initial Engineering Worksheet Answer Records

Status: HISTORICAL DECISION RECORDS / PROMOTED

This directory contains the individual answers to the 20-question initial engineering worksheet.

These files record why each decision was made and which details were deliberately deferred. They are useful planning history, but they are not intended to become a second competing architecture authority.

After a worksheet decision is promoted:
- docs/project-overview.md describes the current product/MVP direction;
- docs/architecture.md describes the current technical boundaries;
- docs/roadmap/initial-roadmap.md describes the current implementation sequence;
- integration/control docs govern their narrower boundaries.

If one of these answer records conflicts with a later promoted architecture, roadmap, contract, ADR, or explicit owner instruction, the later/current authority wins.
