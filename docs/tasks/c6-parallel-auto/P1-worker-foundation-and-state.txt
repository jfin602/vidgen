MUST REMAIN TRUE

- Add a separate `vidgen-worker` package entry point; preserve every existing `vidgen` command and `headline-post` behavior unchanged.
- Support Worker modes `observe`, `generate`, and `live`, plus bounded `--once`, explicit `--process-existing`, and positive `--max-candidates <n>`.

- Keep filesystem state simple; no database, queue, scheduler framework, or distributed-worker abstraction.
- Make time, sleeping, IDs, and external stage runners injectable enough for deterministic tests.
- Treat persisted state as untrusted on read; reject malformed/unsafe state and keep secrets/runtime credentials out of durable records.
- Package and engine version remain 0.6.5.
